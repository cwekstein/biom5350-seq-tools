Sequence utilities for BIOM5350
Edited on Github to test git pull 
Cece Wekstein
BIOM 5350
this repository has python script to calcualte the GC concent, AT content, and mean GC concent from a fasta file

run the script in a unix termical: python gc_content.py example.fasta

the script outputs the sequence name, the GC content, the AT content, the sequence length, and then the mean GC concent of all of the sequences
